# 🎮 Tic Tac Toe – Modern Edition

A modern and visually appealing version of the classic **Tic Tac Toe** game, built using **Python** and **Tkinter**.  
This project provides a smooth, interactive, and colorful graphical interface for two players to enjoy the timeless 3×3 strategy game.

---

## 🧠 Features

- 🕹️ Two-player mode (Player X vs Player O)
- 🧩 Dynamic GUI using **Tkinter**
- 💡 Highlights winning cells with a green background
- 😐 Detects draw situations automatically
- 🔄 Restart button to play again instantly
- ✨ Real-time status updates showing the current player
- 🎨 Modern and responsive interface design
- 💻 Cross-platform compatibility (Windows, macOS, Linux)

---

## 🛠️ Tech Stack

**Programming Language:** Python 3.x  
**GUI Library:** Tkinter (built-in Python library)  

No external installations are required — just Python itself!
